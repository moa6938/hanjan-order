# 음료 주문 MVP

Supabase에 주문을 저장하고 실시간으로 주문 상태를 동기화하는 최소 버전입니다.

## 실행

1. Supabase SQL Editor에서 `supabase/schema.sql`을 실행합니다.
2. `npm install` 후 `npm run dev`를 실행합니다.
3. 주문 화면은 `/#order`, 관리 화면은 `/#admin`입니다.

관리 화면에서 주문용 QR을 확인하고 저장할 수 있습니다. 태블릿에서는 화면을 연 뒤 **알림 켜기**를 한 번 눌러주세요.

## MVP 제한

- 관리자 로그인과 결제 기능은 없습니다.
- 주문 내용에는 개인정보를 입력하지 않는 운영을 권장합니다.
- 현재 관리 화면은 링크를 아는 사람이 접근할 수 있는 초기 운영용 버전입니다.
